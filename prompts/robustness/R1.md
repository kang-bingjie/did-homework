# 稳健性检验：R1 平行趋势正式检验

## 检验目的
验证处理组和对照组在政策实施前（2020年以前）是否满足平行趋势假设。如果处理前各期系数联合不显著，则支持平行趋势假设。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，做 DID 平行趋势正式检验（事件研究法）。将处理前各期（2016-2019年）的虚拟变量加入回归，做联合检验（F检验），检验这些系数是否联合显著不为零。

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 使用企业固定效应 + 年份固定效应
- 标准误聚类到企业层面
- 以政策前第一期（2016年）为基期
- 报告处理前各期（2017、2018、2019年）的系数、标准误、p值，以及联合检验的F统计量和p值
- 不输出政策后各期系数（事件研究图已在课堂项目中提供）

### 【验证】
- 确认回归使用了正确的数据（360家企业，2016-2024年）
- 确认处理前各期虚拟变量定义正确（2017、2018、2019）
- 确认聚类标准误在企业层面
- 输出必须包含联合检验的F值和p值
