# 稳健性检验：T1 处理变量的测量方式

## 检验目的
验证 DID 估计结果是否依赖于"是否数字化"这个 0/1 二元变量的测度方式。通过构造连续的"数字化强度"变量替代二元 `digital` 变量，检验结果是否仍然支持"数字化提升 TFP"的结论，并解释强度变量的边际含义。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，将处理变量从二元变量 `digital`（0/1）替换为连续的**数字化强度**变量，重新估计数字化对 TFP 的影响。

**数字化强度构造方式**：
- 对于处理组企业（`digital=1`），将其 `managerial_capability`（或 `firm_size`）标准化为均值为 0、标准差为 1 的变量
- 数字化强度 = 标准化后的 `managerial_capability` × `digital`
- 对照组企业（`digital=0`）的数字化强度 = 0
- 这样处理组企业之间的数字化强度有差异（管理能力越强，数字化强度越高），对照组为 0

**回归模型**：
用数字化强度替代原 `digital` 变量，保持其他设定不变（控制变量 + 企业固定效应 + 年份固定效应 + 企业层面聚类标准误）。

**解释方式**：
- 系数表示：数字化强度每增加 1 个标准差，TFP 提高多少
- 由于强度变量来自管理能力标准化，可以解释为"管理能力更高的企业，数字化投入强度更大，效应也更大"

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 只替换处理变量，不改变其他设定
- 如数据中 `managerial_capability` 不存在，使用 `firm_size` 替代（先检查数据中可用的变量名并告知用户）
- 标准化时使用全样本（处理组 + 对照组）的均值和标准差
- 不将"数字化强度"的系数与基准 `digital` 的系数直接对比量级（含义不同），只对比方向和显著性

### 【验证】
- 确认数字化强度变量已正确生成（处理组为标准化值 × 1，对照组为 0）
- 确认处理组企业的数字化强度存在差异（不只是 0 和 1）
- 检查新系数的方向是否与基准一致（仍为正）
- 检查新系数是否显著（p < 0.1）
