# 稳健性检验：R7 样本调整

## 检验目的
验证 DID 估计结果是否受特定样本选择的影响。通过三种样本调整策略（①剔除电子行业、②剔除最大/最小5%企业、③缩短时间窗口），重新运行主回归，检验系数是否基本不变。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，在三种不同的样本调整方案下分别运行 DID 主回归，比较 DID 系数的变化：

- **模型 1**：剔除电子行业（`industry` == "电子"）——因为电子行业处理组最集中（60%企业为处理组），可能驱动结果
- **模型 2**：剔除 `log_tfp` 最大和最小的各 5% 企业（基于全样本计算分位数）
- **模型 3**：缩短时间窗口，仅保留 2018–2022 年（去掉政策前较远的年份 2016、2017 和政策后较远的年份 2023、2024）

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 除样本调整外，所有模型保持相同的变量设定（digital + 控制变量 + 企业固定效应 + 年份固定效应 + 企业层面聚类标准误）
- 不改变任何变量的定义
- 如果数据中行业名称不叫"电子"，先检查数据中的行业名称，替换为对应的处理组最集中的行业名称（先检查数据中可用的行业名称并告知用户）

### 【验证】
- 确认三个模型的样本量变化合理
- 检查 DID 系数与基准系数相差是否在 20% 以内
- 检查系数方向是否一致
- 检查显著性是否保持不变
- 如果某个模型系数变化较大（超过 20%），标记为"需关注：该样本调整对结果影响较大"
