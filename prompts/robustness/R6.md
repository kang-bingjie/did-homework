# 稳健性检验：R6 极端值处理（Winsorize）

## 检验目的
验证 DID 估计结果是否受结果变量极端值的影响。通过对 `log_tfp` 进行 1% 和 99% 的 Winsorize（缩尾）处理，将极端值替换为边界值，重新运行主回归，检验系数是否基本不变。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，对结果变量 `log_tfp` 进行 1%/99% Winsorize（缩尾）处理后，重新运行 DID 主回归，比较系数是否与基准结果基本一致。

具体操作：
1. 计算 `log_tfp` 的 1% 分位数和 99% 分位数
2. 将所有小于 1% 分位数的值替换为 1% 分位数
3. 将所有大于 99% 分位数的值替换为 99% 分位数
4. 生成新变量 `log_tfp_wins` 
5. 用 `log_tfp_wins` 替代 `log_tfp`，重新运行完整的主回归模型

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 只处理结果变量，不处理任何其他变量
- 保持与基准回归相同的控制变量、固定效应和聚类层级
- 不讨论 Winsorize 的具体阈值选择（使用标准 1%/99%）

### 【验证】
- 确认 Winsorize 后的变量已正确生成（极值已被替换）
- 检查 DID 系数与基准系数相差是否在 10% 以内
- 检查系数方向是否一致
- 检查显著性是否保持不变
