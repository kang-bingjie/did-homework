# 稳健性检验：R3 替换结果变量

## 检验目的
验证 DID 估计结果是否依赖于 TFP 的特定测算方式。用劳动生产率（`labor_productivity`）替代 `log_tfp` 作为结果变量，重新运行主回归，检验系数方向与显著性是否一致。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，将结果变量从 `log_tfp` 替换为 `labor_productivity`（或 `log(labor_productivity)`），重新运行 DID 主回归，比较系数方向、显著性和量级是否与基准结果一致。

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 只替换结果变量，不改变处理变量、控制变量、固定效应、聚类层级
- 与基准回归保持相同的模型设定（企业固定效应 + 年份固定效应 + 聚类标准误）
- 如果数据中 `labor_productivity` 不存在，使用 `log(labor_productivity)`（先检查数据中可用的变量名）

### 【验证】
- 确认替代结果变量存在且计算正确
- 确认回归使用了与基准相同的固定效应和聚类层级
- 检查新系数是否与基准系数方向一致（同为正或同为负）
- 检查新系数是否在 10% 水平上显著
