# 稳健性检验：R4 改变控制变量集合

## 检验目的
验证 DID 估计结果是否依赖于特定的控制变量组合。通过三种控制变量设定（①不加控制变量、②加入全部控制变量、③额外加入 `firm_size`），比较 DID 系数的变化幅度，判断结果是否对模型设定敏感。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，在三种不同的控制变量集合下分别运行 DID 主回归，比较 DID 系数的变化：

- **模型 1**：不加任何控制变量（仅 digital + 企业固定效应 + 年份固定效应）
- **模型 2**：加入全部控制变量（capital_intensity + export_share + ownership + 企业固定效应 + 年份固定效应）——即基准模型
- **模型 3**：在模型 2 基础上额外加入 `firm_size`（规模）

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 除控制变量外，所有模型保持相同的固定效应（企业固定效应 + 年份固定效应）和聚类层级（企业层面）
- 不添加任何数据中不存在的变量
- 不改变处理变量（digital）的定义

### 【验证】
- 确认三个模型的样本量一致
- 检查 DID 系数在不同模型间的变化幅度（是否稳定）
- 检查 DID 系数的显著性是否变化（是否从显著变为不显著）
- 如果系数变化较大（如超过 20%），标记为"需关注"
