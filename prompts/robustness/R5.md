# 稳健性检验：R5 改变聚类层级

## 检验目的
验证 DID 估计结果的标准误和显著性是否依赖于特定的聚类层级选择。通过在行业（`industry`）、地区（`province`）和企业三个不同层级聚类，比较标准误的变化，判断结果是否对聚类层级敏感。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，在三种不同的聚类层级下分别运行 DID 主回归，比较标准误和显著性的变化：

- **模型 1**：聚类到企业层面（`firm_id`）——即基准模型
- **模型 2**：聚类到行业层面（`industry`）
- **模型 3**：聚类到地区层面（`province`）

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- 除聚类层级外，三个模型保持相同的变量设定（digital + 控制变量 + 企业固定效应 + 年份固定效应）
- 不改变任何变量的定义
- 如数据中无 `province` 变量，用 `region` 替代（先检查数据中可用的变量名并告知用户）

### 【验证】
- 确认三个模型的 DID 系数完全一致（因为只改变了聚类层级）
- 检查标准误在不同聚类层级下的变化幅度
- 检查显著性是否发生变化（如从显著变为不显著）
- 如果标准误变化较大（如超过 30%），标记为"需关注"
