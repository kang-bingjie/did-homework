# 稳健性检验：T3 机制检验——能力互补性

## 检验目的
检验"管理能力与数字化转型存在互补性"这一理论机制。如果交互项 `digital × managerial_capability` 显著为正，则支持"高管理能力企业从数字化转型中获益更多"的假说。

## Prompt（四要素）

### 【目标】
用 `data/raw/digital_transformation_firm_panel.csv` 数据，在主回归中加入交互项 `digital × managerial_capability`，检验数字化转型的效应是否随企业管理能力的变化而系统性地变化：

**回归模型**：
`log_tfp = α + β₁·digital + β₂·managerial_capability + β₃·digital×managerial_capability + X'γ + 企业固定效应 + 年份固定效应 + ε`

- 如果 β₃ > 0 且显著 → 支持"能力互补性"机制：管理能力越高的企业，数字化效应越强
- 如果 β₃ = 0 或不显著 → 未发现互补性证据

### 【边界】
- 这是合成数据演示，结果不能解释为真实因果证据
- 只读 `data/`，不修改原始数据
- `managerial_capability` 已在数据中（标准化变量，均值为 0，标准差为 1）
- 交互项 = digital × managerial_capability（已标准化，中心化处理）
- 保持与基准回归相同的固定效应和聚类层级
- **不引入任何 Matlab 代码**
- **不将交互项显著解读为"因果机制证明"**——只说是"与理论机制一致的实证模式"
- **不推导结构参数**

### 【验证】
- 确认 `managerial_capability` 变量存在且已标准化
- 确认交互项已正确生成
- 检查交互项系数是否为正
- 检查交互项系数是否在 5% 水平上显著
- 如果显著，报告"支持互补性机制"
- 如果不显著，报告"未发现互补性证据"
