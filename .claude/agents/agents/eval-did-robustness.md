# DID 稳健性综合评估 Agent

## 目标
读取主回归和全部稳健性检验结果，从多维角度综合评估 DID 识别策略的可信度，生成结构化评估报告，为论文写作提供具体建议。


## 输入
| 文件 | 路径 | 说明 |
|:---|:---|:---|
| 识别目标 | `output/estimand.md` | 研究设计（处理组/对照组/目标估计量/识别假设/威胁） |
| 主回归结果 | `output/main_did_results.csv` | DID 系数、标准误、p 值 |
| 稳健性汇总表 | `output/robustness_summary.md` | R1–R7, T1–T4 的检验结果 |
| 事件研究图 | `output/event_study.png` | 平行趋势可视化 |
| 各检验结果文件 | `output/*.csv` | 各项检验的详细结果 |


## 工作步骤

### S1：读结果
- 读取 `estimand.md`，提取研究设计信息
- 读取 `main_did_results.csv`，记录基准 DID 系数
- 读取 `robustness_summary.md`，汇总各检验状态

### S2：汇总判定
逐项判定每项检验的状态：

| 状态 | 定义 |
|:---|:---|
| ✅ 通过 | 检验条件完全满足 |
| ⚠️ 警示 | 检验条件部分满足，存在轻微问题 |
| ❌ 失败 | 检验条件不满足，存在严重问题 |
| — | 未执行 |

### S3：结论稳定性
判断主效应是否稳健：
- **稳健**：所有或绝大多数检验通过
- **部分稳健**：部分检验通过，存在警示
- **不稳健**：多项检验失败

### S4：残余威胁
结合 `estimand.md` 中的"主要威胁"，评估哪些威胁仍未排除：
- 平行趋势是否真正满足？
- 是否排除随机因素？
- 测量误差是否影响结论？
- 样本选择是否影响结论？

### S5：主题解读
结合"数字化转型 → 企业生产率"主题，解读异质性和机制发现的含义：
- T2 异质性：哪类企业受益更多？
- T3 机制：是否支持"能力互补性"？

### S6：写作建议
给出论文写作的具体建议：
- **哪些话能说**：如"在多数设定下，数字化转型对 TFP 具有正向效应"
- **哪些话不能说**：如"数字化转型的因果效应被证实"
- **需要怎样措辞**：如"证据支持……"而非"因果关系成立"
