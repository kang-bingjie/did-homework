## Techniques to Avoid

| Technique | Why It Fails | Evidence |
| --------- | ------------ | -------- |
| 无边界的技术深入（MLE/算法设计） | 超出课程核心目标，挤占关键内容时间 | L04/05: MLE 5分钟+算法设计8分钟 → 教师自认应压缩 |
| 无总结的突然结尾 | 学生缺乏认知闭合，关键要点未巩固 | L04/05: "好，今天的课就到家"；Invited: "好，我就讲到这么多，接下来我们给大家交流的时间" |
| 连续demo无检查点 | 观众无法消化，认知负荷累积，后半段注意力下降 | Invited: 75分钟连续demo，工具切换6+次，无任何观众检查点或消化停顿 |
| "幽灵提问" — 问"有什么问题吗"但立即继续讲 | 信号开放但行为关闭，观众困惑是否可以真提问 | Invited-RUC: line 590 "有什么问题没有...我们不要听"→继续讲 → 讲师自认节奏问题 |
| "开放邀请替代主动停顿" — 开场说"随时可以打断我"但之后75分钟从未停顿 | 给讲师心理满足感（"已邀请互动"），但实际没有改变教学节奏 | Invited-CUFE: line 291 "大家有问题可以随时打断我"→之后75分钟无任何主动停顿。讲师自认"觉得'随时打断'就够了"，但已认识到需要"主动设置"检查点 |

### Technique 原因分析（来自苏格拉底式访谈 2026-06-14 + CUFE访谈 2026-06-14）

**收尾仪式缺失**：讲师认为"Slide即总结"——slides已有结束语，口头重复是冗余。但教学研究显示口头+视觉双重编码产生更强记忆。**修正**：不用重复slides文字，而用不同角度做口头收尾（如"今天如果只记住一件事……"），既不重复又提供认知闭合。**更新（CUFE访谈）**：此认知在两场访谈中完全一致，说明是深层认知模式，非短期可改变。需要找到匹配其"不重复"偏好的收尾方案。

**Demo节奏**：讲师选择连续demo是担心停顿打断观众"沉浸感"。**修正**：demo开始前宣布"随时举手打断"，保留沉浸感同时打开互动通道。**更新（CUFE访谈）**：讲师已实践了"随时打断我"的口头邀请，但自认这已足够——未意识到开放邀请在75分钟高速demo中几乎不可能被观众使用。学习曲线：同意加入检查点(RUC)→用口头邀请实现(CUFE实践)→认识到需要主动停顿(CUFE反思)。第三场讲座是这一学习曲线的真正测试点。

**"幽灵提问"**：当讲师问"有问题吗"但立即继续讲，说明他在焦虑时间和保持流畅之间摇摆。**修正**：要么不问（直接进入下一环节），要么问后默数3秒再继续。

**新slides未被口头激活（新增，CUFE 2026-06-14）**：讲师自认"忘记了"野马比喻。slides更新不等于教学更新——新slides需要明确的"口头钩子"（故事、类比、演示动作）才能在现场被自然激活。**修正**：备课时在每个关键slide的speaker notes中写一句口头钩子。

## Recurring Student Confusion Points

| Topic | Confusion | Better Explanation Strategy |
| ----- | --------- | -------------------------- |
| 内生性(endogeneity)术语 | 学生不理解"内""外"指什么 | 从结构方程出发：系统内变量vs系统外政策抓手 |
| 平衡性检验的含义 | 学生可能认为通过=验证了CIA | 明确区分：通过检验=可观测特征相似，不等于不可观测也相似 |
